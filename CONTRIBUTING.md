# Contribuindo

Issues e pull requests são bem-vindos. Este repositório tem um único mantenedor, e todo código novo entra por PR revisado e mergeado por ele; não há outros colaboradores com permissão de push.

Para copiar, adaptar ou redistribuir qualquer coisa daqui, não precisa pedir: a licença MIT em [LICENSE](LICENSE) já autoriza.

## Antes de abrir um PR

- Uma skill é um diretório em `skills/` com um `SKILL.md`, que o agente lê, e um `README.md`, para humanos. Mantenha os dois em sincronia.
- Escreva o `SKILL.md` seguindo a skill `writing-for-agents`.
- Para mudanças grandes ou novas skills, abra uma issue antes para alinhar a ideia.
